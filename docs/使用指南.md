# 使用指南

## 使用

- `/搜歌 歌名、歌手或关键词`，也可使用 `/音乐`。指令直接搜索，不调用聊天模型。
- AI工具名为 `search_music`，参数为关键词和可选候选数量。是否调用由模型选择；音乐插件本身不另调大模型。
- 默认返回歌名和播放页面，无需签名密钥。搜索服务网络可用是必要条件，播放页面不表示会员音源下载。
- 选择机器人签名卡片时，网易云使用数字歌曲编号，QQ音乐使用数字卡片编号；需要支持音乐分享的QQ客户端与签名配置。
- 独立签名服务地址由管理员填写，使用HTTPS，预期返回 `code:200` 及 `data` 中的音乐卡片对象；服务格式参数通常留空。
- 标准自定义卡片需要真实公开音源；没有音源或发送失败时返回歌曲信息，不伪造播放地址或随机签名。其他消息适配器使用链接文本。

## 配置与升级

配置按开始使用、歌曲信息、搜索缓存和独立签名服务分类。候选上限默认8首，卡片默认1张，搜索缓存默认120秒，关闭或重启即清空内存缓存。没有聊天数据库和个人预置数据。

旧 `ark` 本地模式转换为标准自定义卡片，不再使用 `ark_token`、`ark_bizsrc` 或 `ark_appid` 伪造本地签名。旧音源、数量、显示、超时及签名设置保留；不要把旧配置文件上传公开仓库。

卡片部分失败时仅列出确认发送成功的歌曲，未成功歌曲仍提供查询结果；重载、退出会关闭异步连接。插件不清空历史、不改写system提示、不追加每轮系统内容、不修改框架类或其他插件的方法。
